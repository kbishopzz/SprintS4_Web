# React Component Map

## Public Components

- `AirportSelector.jsx`
  - Dropdown to select current airport
- `ArrivalsBoard.jsx`
  - Displays arriving flights for selected airport
- `DeparturesBoard.jsx`
  - Displays departing flights for selected airport

## Admin Components

- `AdminDashboard.jsx`
  - Layout for admin section
- `FlightsAdmin.jsx`
  - List, create, update, delete flights
- `AircraftAdmin.jsx`
  - List, create, update, delete aircraft
- `AirlinesAdmin.jsx`
  - List, create, update, delete airlines
- `GatesAdmin.jsx`
  - List, create, update, delete gates

## Auth Components

- `Login.jsx`
  - Username/password login form
- `ProtectedRoute.jsx`
  - Wraps routes that require authentication

## Shared Components

- `Navbar.jsx`
- `Footer.jsx`
- `ApiClient.js` (Axios wrapper)
- `AuthContext.js` (auth state and helpers)
