## User Stories

User Story 1: User created a new account and Logged in successfully. The user creates a flight plan for themselves (user name: James Blake).

User Story 2: New Customer walks into the airport and wants to book a flight. The customer is able to search for available flights, select a flight, and complete the booking process.

User Story 3: The user wants to view their flight history. The user is able to access their account and view a list of all the flights they have booked in the past.

User Story 4: The passenger wants to check in for their flight at Kiosk. The passenger is able to enter their booking reference and personal information, and the kiosk prints out their boarding pass.
